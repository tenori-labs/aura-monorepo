# **App Name**: Campus Watch

## Core Features:

- Incident Reporting: Secure and anonymous form for reporting incidents.
- Report Tracking: Dashboard to track submitted reports and their status.
- AI Report Classifier: AI powered "tool" to categorize reports based on keywords and patterns to help speed report administration.
- Information and Resources: FAQ section addressing common questions and concerns.
- Admin Interface: Admin portal for college staff to view, assign, and manage incident reports.

## Style Guidelines:

- Primary color: Deep Blue (#3F51B5) to evoke trust and authority.
- Background color: Light Gray (#F0F2F5) for a clean and neutral backdrop.
- Accent color: Teal (#009688) for interactive elements and highlights, creating a sense of calm and security.
- Use clear and readable sans-serif fonts for all text elements.
- Use simple, recognizable icons for navigation and report categories.
- Clean and organized layout to ensure ease of use and navigation.
- Subtle transitions and animations to provide feedback without being distracting.
